.. _whatsnew:

What's New
==========

This page lists the main new capabilities of FEPX version 3.0.0 since version 2.1.0, the latest release of version 2, starting with some highlights.  FEPX 3 does not read FEPX 2 inputs unchanged, see :ref:`whatsnew_incompatible`.

.. _highlights:

Highlights
----------

A New, Faster Code
~~~~~~~~~~~~~~~~~~

FEPX has been rewritten from the bottom up, in modern Fortran, keeping the established solution methods of version 2.  The crystal behavior uses the full anisotropic stiffness: the hydrostatic and deviatoric parts are no longer decoupled.  The results do not depend on the number of processes, and every release passes a suite of unit, verification (analytic solutions) and regression tests, run on 1, 2 and 4 processes.

FEPX also runs faster: about 2.8 times faster than version 2 on a 100-grain polycrystal of 26,000 elements, on 1, 2 and 4 processes, thanks to faster crystal-level computations and a block-Jacobi preconditioner of the conjugate gradient solver, which needs 18% fewer iterations.  Small meshes run with many increments are about as fast as with version 2.  See :doc:`doc/running`.

Stress Control and Mixed Targets
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. grid:: 1 1 2 2
   :gutter: 4

   .. grid-item::

      Each step of a loading now ends at a strain, time, load or stress target (:confval:`target_strain`, :confval:`target_time`, :confval:`target_duration`, :confval:`target_load`, :confval:`target_stress`), and loads and stresses can be applied at a rate (:confval:`load_rate`, :confval:`stress_rate`), so that loading, unloading to zero stress and reloading are written in a few lines:

      .. code-block:: none

        number_of_steps 3
        strain_rate       33    1.0e-3   -1.0e-3    1.0e-3
        target_strain     33    0.010     -         0.015
        target_stress     33    -         0.0       -

      See :doc:`doc/tutorials/mixed_targets`.

   .. grid-item::

      .. image:: imgs/whatsnew/mixed-targets.png
         :class: fepx-whatsnew-img

Slip Families and Per-Family Parameters
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. grid:: 1 1 2 2
   :gutter: 4

   .. grid-item::

      The active slip families are chosen with :confval:`slip_families` (including the {110}, {112} and {123} families for bcc crystals), and :confval:`m`, :confval:`gammadot_0` and :confval:`tau_0` take one value per family.  Here, for an hcp crystal (basal, prismatic and pyramidal :math:`\langle c+a \rangle` families):

      .. code-block:: none

        m 0.01 0.01 0.01
        gammadot_0 1.0 1.0 1.0
        tau_0 390.0 468.0 663.0

      See :doc:`doc/tutorials/hcp_single_crystal`.

   .. grid-item::

      .. image:: imgs/whatsnew/hcp-slip.png
         :class: fepx-whatsnew-img

Kocks--Mecking Hardening and Irradiation
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The slip-system strengths can now follow Kocks--Mecking dislocation-density hardening (:confval:`hardening` ``kocks_mecking``), with optional irradiation softening by dislocation loops (:confval:`irradiation`), for fcc and bcc crystals:

.. code-block:: none

  hardening kocks_mecking
  km_b 2.48e-7
  km_h_n 0.125
  km_k1 4.5e5
  km_k20 14.0
  km_gammadot_k0 1.0e10
  km_n 100.0
  km_rho_0 2.0e7

See :ref:`keyword_reference`.

20-Node Hexahedral Elements
~~~~~~~~~~~~~~~~~~~~~~~~~~~

In addition to 10-node tetrahedra, FEPX now runs on 20-node hexahedral meshes generated by Neper.  See :doc:`doc/fileformat`.

HDF5 Output for ParaView
~~~~~~~~~~~~~~~~~~~~~~~~

Results can now be written as an HDF5 file with its XDMF file, read by ParaView, and by Python with h5py, in addition to or instead of the text files of :file:`simulation.sim` (:confval:`output_format`).  All results are written unrounded.  See :doc:`doc/output` and :doc:`doc/tutorials/postprocessing`.

Exact Restart
~~~~~~~~~~~~~

A restart point is written at the end of every step, and holds the whole state of the simulation.  On the same number of processes, a simulation interrupted and continued with further steps gives the same results, bit for bit, as an uninterrupted run, and the results are appended to the same :file:`simulation.sim` directory.  See :ref:`restart` and :doc:`doc/tutorials/restart`.

New Capabilities by Area
------------------------

Crystal Behavior
~~~~~~~~~~~~~~~~

- Elastic phases (:confval:`model` ``elastic``), alone or together with crystal-plasticity phases (:confval:`model` ``crystal_plasticity``).
- Independent :confval:`c33` for hcp and bct crystals (FEPX 2 imposed :math:`C_{33} = C_{11} + C_{12} - C_{13}` for hcp).
- Selection of the active slip families (:confval:`slip_families`), including the bcc {123} family, and :confval:`m`, :confval:`gammadot_0` and :confval:`tau_0` per family.
- :confval:`h_0`, :confval:`tau_s` and :confval:`n` per family or per system with anisotropic hardening (:confval:`hardening` ``saturation_anisotropic``), and a general :confval:`interaction_matrix`, given row by row.
- Cyclic hardening (:confval:`cyclic_hardening`) also with anisotropic hardening.
- Kocks--Mecking dislocation-density hardening (:confval:`hardening` ``kocks_mecking``), with optional irradiation softening (:confval:`irradiation`).

Loading
~~~~~~~

- Stress targets and rates (:confval:`target_stress`, :confval:`stress_rate`), and time targets and durations (:confval:`target_time`, :confval:`target_duration`), which can be mixed from step to step.
- Load and stress targets reached within a tolerance (:confval:`load_tol`, :confval:`stress_tol`), and steps that end exactly on their targets, with a shorter last increment if needed.
- Dwells written as steps at zero load rate, with a duration.
- A single syntax for all boundary conditions: :confval:`boundary_conditions` with presets, and one row per loaded component (:confval:`control_component`, :confval:`strain_rate`, ...), with one value per step.

Solver
~~~~~~

- Block-Jacobi preconditioner of the conjugate gradient solver, used by default (:confval:`cg_preconditioner`).
- Automatic subincrementation of the increments that do not converge (:confval:`subincrementation`).
- Choice of the initialization of crystal-plasticity runs (:confval:`initialization`), by default a small elastic step before the first increment.
- Results that do not depend on the number of processes.

Output
~~~~~~

- HDF5 and XDMF output (:confval:`output_format`).
- Results written unrounded, with 17 significant digits.
- ``strain_pl_sample``, the plastic strain accumulated in the sample frame.
- Convergence information written inside the simulation directory (``print convergence``).
- Restart points written at the end of every step, with the whole state, inside the simulation directory (:ref:`restart`).

General
~~~~~~~

- Strict reading of the configuration file, with clear error messages, listed in :doc:`doc/messages`.
- Complete reference of the keywords and of the options that cannot be combined (:ref:`keyword_reference`, :ref:`compatibility`).
- Conda packages for Linux and macOS (an Open MPI and an MPICH build), and a CMake build from source (:ref:`installation`).
- Unit, verification and regression tests, run on 1, 2 and 4 processes (:ref:`installation_testing`).

.. _whatsnew_incompatible:

Incompatible Changes
--------------------

.. warning::

  FEPX 3 does not read FEPX 2 inputs unchanged, and it has no compatibility mode: an obsolete keyword or value is an error, so that an old file fails clearly instead of being misread.  See :ref:`porting` for how to port an FEPX 2 simulation.

- Only Neper mesh files of version 2.4 are read: regenerate older meshes with a current Neper, or re-save them.
- Many keywords of :file:`simulation.cfg` are renamed or replaced, in particular :data:`g_0` and :data:`g_s0` (now :confval:`tau_0` and :confval:`tau_s`), :data:`hard_type` (now :confval:`hardening`), :data:`def_control_by` and the triaxial loading keywords (now :confval:`boundary_conditions`, :confval:`control_component` and the target and rate rows), and the solver tolerances.
- Each phase states its model (:confval:`model`), and hcp crystals need :confval:`c33`.
- Rows of the loading give one value per step (FEPX 2 repeated the last value).
- :confval:`max_strain` and :confval:`max_eqstrain` have no default (no limit).
- Output names use underscores only (e.g., ``strain_el``, not ``strain-el``), and :data:`suppress` is removed.
- FEPX 2 restart files cannot be read.
