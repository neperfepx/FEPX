Installing with Conda
---------------------

The simplest way to install FEPX (Linux and macOS) is from `conda-forge <https://conda-forge.org>`_:

.. code-block:: console

  $ conda create -n fepx -c conda-forge fepx
  $ conda activate fepx

See :ref:`installation_conda` for details.

Current Official Release
------------------------

The current official release (and previous ones) is available from the `Releases <https://github.com/neperfepx/FEPX/releases>`_ section of the `GitHub repository <https://github.com/neperfepx/FEPX>`_.

Latest Version
--------------

The latest version is available on the :code:`main` branch of the `GitHub repository <https://github.com/neperfepx/FEPX>`_.  To get the latest version as a Git user, run:

.. code-block:: console

  $ git clone https://github.com/neperfepx/FEPX.git

which will download the repository.  To update the repository at any later time, run:

.. code-block:: console

  $ git pull origin main

from within the repository.

To get the latest version as a non-Git user, run:

.. code-block:: console

  $ wget https://github.com/neperfepx/FEPX/archive/refs/heads/main.zip

which will download only the latest version.  Alternatively, you may click on :data:`Code` / :data:`Download ZIP` on the `GitHub repository <https://github.com/neperfepx/FEPX>`_.

The `GitHub repository <https://github.com/neperfepx/FEPX>`_ is also the place for interactions, see the :ref:`community` page.
