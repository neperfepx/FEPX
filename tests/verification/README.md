# Verification tests

Simulations checked against analytic solutions (CLAUDE.md §6), run with the FEPX executable
(step 4.4 on). Label `verification`. The v2-fixed cases (`verification_v2_*`, run with v2's
executable) were removed with v2 in step 9.13 (ROADMAP D90); they and their descriptions are in
the tag `v2-final-comparison`.

```
ctest --test-dir build -L verification --output-on-failure
```

Each test runs a case from `cases/` with `tests/regression/run_case.cmake` (copy to the build tree,
run with MPI) and then a Python check script; there is no reference data.
