.. _introduction:

Introduction
============

Description
-----------

FEPX is a finite element software package for polycrystal plasticity [DAWSON2015]_. It models the global and
local mechanical behavior of polycrystalline solids as aggregates of grains, and the associated
microstructural evolution, in a parallel (MPI) framework. Each grain is discretized by finite
elements which have a crystal behavior. This includes:

- nonlinear kinematics capable of resolving large (finite) strains and large rotations;

- anisotropic elasticity based on crystal symmetry, with the full anisotropic stiffness;

- anisotropic plasticity based on rate-dependent slip restricted to dominant slip systems,
  with saturation-type slip-system hardening (isotropic or anisotropic, with saturation
  evolution, cyclic hardening and precipitate strengthening), and Kocks--Mecking
  dislocation-density hardening with optional irradiation softening;

- state variable evolution for the crystal lattice orientation and the slip system strengths.

FEPX is written in modern Fortran, with MPI for parallel computing. All input data are given
non-interactively in text files. FEPX works
hand in hand with `Neper <https://neper.info>`_, which generates the polycrystal meshes and
post-processes the results [IOP2022]_.

FEPX's capabilities include:

- elastic and crystal-plasticity phases of cubic (``fcc``, ``bcc``), hexagonal (``hcp``) and
  tetragonal (``bct``) crystals, with per-element-set or per-element orientations and
  parameters;
- 10-node tetrahedral and 20-node hexahedral meshes generated by Neper, partitioned over the MPI
  processes;
- loadings of one or more steps: uniaxial boundary-condition presets, triaxial strain and load
  control, general velocity conditions, multi-point constraints and periodic conditions;
- strain, time, load and stress targets, and load and stress rates (with dwells);
- nodal, elemental and slip-system results as text files (the :file:`simulation.sim`
  directory, read by Neper) or HDF5 with an XDMF file for ParaView;
- restart of a simulation with further loading steps.

The combinations of options that are not supported are listed in :ref:`compatibility`.

Resources and Support
---------------------

Several complementary resources describing FEPX are available:

- The FEPX documentation, the document you are reading, provides a detailed overview of all
  of FEPX's capabilities. Specific sections are dedicated to simulation input and output,
  running simulations, and example simulations (:ref:`tutorials`).

- The FEPX website, `<https://fepx.info>`_, gives a general introduction to FEPX with
  illustrative examples.

- The `FEPX GitHub repository <https://github.com/neperfepx/FEPX>`_ is where the latest version
  is available and where user interactions take place:

  - To get and keep up-to-date with the latest version, clone the repository using:

    .. code-block:: console

      $ git clone https://github.com/neperfepx/FEPX.git

    which gives access to the latest stable release on the default, ``main`` branch. To update
    your local repository, run :command:`git pull` from within the repository.

  - To report bugs or request new features, use the `issue tracker
    <https://github.com/neperfepx/FEPX/issues>`_. When reporting bugs, please provide a minimal
    working example and the FEPX terminal output.

  - To ask questions or share comments, use the `discussion forum
    <https://github.com/neperfepx/FEPX/discussions>`_.

- The two FEPX reference papers (see also :ref:`citing`):

  .. [DAWSON2015] `P.R. Dawson and D.E. Boyce, FEPX -- Finite Element Polycrystals: Theory,
     Finite Element Formulation, Numerical Implementation and Illustrative Examples,
     arXiv:1504.03296, 2015, <https://arxiv.org/abs/1504.03296>`_ describes the underlying
     mechanical theory and finite element methods (its descriptions of simulation input and
     output are of an earlier version);

  .. [IOP2022] `R. Quey and M. Kasemer, The Neper/FEPX project: free / open-source polycrystal
     generation, deformation simulation, and post-processing, IOP Conference Series: Materials
     Science and Engineering 1249, 012021, 2022,
     <https://iopscience.iop.org/article/10.1088/1757-899X/1249/1/012021/meta>`_ describes the
     use of FEPX with Neper.

Resources for Neper can be accessed from `<https://neper.info>`_.

Installing FEPX
---------------

FEPX can be installed using conda, which is the simplest method, or compiled from its source
code. See :ref:`installation`, which also describes the build options and the test suite.

Getting Started
---------------

A simulation needs two files in the working directory: the mesh file :file:`simulation.msh`,
which describes the polycrystal (see :ref:`mesh_file`), and the configuration file
:file:`simulation.cfg`, which defines the simulation (see :ref:`config_file`). Run FEPX from
that directory on ``<N>`` MPI processes with:

.. code-block:: console

  $ mpirun -np <N> fepx

FEPX writes progress messages to the terminal and the results to the simulation directory
:file:`simulation.sim` (see :ref:`simulation_results`), which Neper reads. See
:ref:`running` for the number of processes and the messages.

Conventions Used in This Documentation
--------------------------------------

- A command entered at the terminal is shown as

  .. code-block:: console

    $ command

  where ``$`` is the prompt, not typed.

- Keywords and literal values are printed like ``this``; a value to be replaced is printed like
  ``<this>``; optional input is shown between brackets, ``[ <this> ]`` (the brackets are not
  typed).

- File names are printed like :file:`this`.

- Units: FEPX uses MPa, mm, s and K throughout (forces in N).

- Symmetric tensors are written as their six tensor components in the order 11, 22, 33, 23,
  13, 12.

Development History
-------------------

The development of FEPX began in the late 1990s, led by Paul Dawson, and involved many members
of the Deformation Process Laboratory (DPLab) at Cornell University, USA, until early 2020. An
extended development history contributed by Paul Dawson, the lead investigator of the DPLab, can
be found in :ref:`development_history`. Ongoing development has since been led by Matthew
Kasemer (Advanced Computational Materials Engineering Laboratory (ACME Lab), The University of
Alabama, USA) and Romain Quey (CNRS, Mines Saint-Étienne, France), and involved other members of
their respective groups.
